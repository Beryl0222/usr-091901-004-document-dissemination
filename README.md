# 历史文献传播谱系

记录手稿、连载、单行本、译本、内部资料、公开本与再版之间的来源和授权关系。项目以领域契约约定参与者、状态、术语和不可破坏的业务原则；基础服务提供稳定的运行检查与契约读取接口；领域层把长征早期文献专题式的编目、考证、授权与出版规则落成可执行代码。

## 运行

```bash
python3 service.py --check            # 核对服务与领域契约
python3 service.py --port 8000        # 后访问 /health 与 /contract
python3 -m unittest -v                # 全部测试（基础契约 + 领域场景）
```

## 领域契约（domain_contract.json）

契约 v1.1 约定：

- **实体**：作品、作品异名、文献版本、刊物期次、证据定位、身份/源流主张、编辑事件、争议、授权许可、素材、导出申请、专题、专题说明、出版快照、补充版本。
- **版本类型**：手稿、来稿、连载、单行本、合刊、译本、内部资料、公开本、补充版本。
- **确定程度**：确证、较大可能、存疑、争议中。
- **关系类型**：连载于、汇编入、再版为、译自、吸收来稿、复用段落、补充订正。

核心不变量：

1. “最早”“首部”“源自某稿”等结论必须引用至少一条可定位证据（馆藏索取号、刊物卷期页码、书影扫描件或档号），并标注确定程度；无证据只能登记为待考，不得出版。
2. 竞争性作者、笔名、底本观点允许并存，互不覆盖。
3. 出版快照一经冻结不可改写；新见书影、署名考证、页码订正只能以**补充版本追加**，再版时形成引用旧版的新快照，旧版始终可复原。
4. 素材导出须同时通过**馆藏许可有效、清晰度达标、地域使用范围覆盖**三项核验。
5. 专题中每句说明都可回溯到采用的文献版本、贡献者（含笔名署名）、授权与历次争议。

## 领域层（domain.py）

`Archive` 提供主要用例：

- 作品异名逐个保留、缺卷登记依据；版本失佚/重见全程留痕。
- `add_claim` / `register_conjecture`：有证据的主张与待考猜测分开；`open_dispute` 将竞争主张并置为“争议中”。
- 多底本：译本可整体“译自”一个底本，并按段落挂接其他底本；`absorb_submissions` 逐篇登记公开本吸收的亲历者来稿。
- 跨书复用：以文字段为单位登记各书出现位置后再建立复用关系。
- `apply_export`：按用途、地域、清晰度要求返回三项核验结果与逐条驳回原因。
- `add_statement` / `publish_topic` / `supplement_*` / `publish_new_edition`：说明必须挂齐主张、版本与授权才能出版；出版后只追加补充。
- `trace_statement`：从快照中的一句说明回到版本、贡献者、证据、授权和争议；`lineage` 给出任一版本的完整源流与编辑事件。

`test_domain.py` 以“随军西行见闻录”式场景（笔名连载、中文本一度失佚、英译本多底本、公开本吸收 212 篇来稿、署名之争、三类补充版本、导出驳回）覆盖以上规则。
